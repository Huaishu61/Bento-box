# Bento-box
My first vibe coding project with my roommate.
1. Bento Box（便当盒）风格的极简个人主页
现在非常流行那种像一块块“便当盒”一样拼接起来的个人主页（比如展现你的歌单、GitHub 状态、座右铭、社交链接）。

成就感来源：这会是你的一张“数字名片”。你可以利用 GitHub Pages 直接免费部署它，拥有属于自己的专属网址（你的用户名.github.io）。

Vibe 姿势：你可以给 AI 这样的指令：“帮我写一个纯前端的 Bento 风格个人主页，使用暗黑模式，鼠标悬停在每个模块上时要有霓虹灯发光的过渡动画。不需要复杂的框架，就用 HTML、CSS 和一点点 JS。”

练习的 GitHub 技能：使用 Git 提交代码、配置 GitHub Pages 静态部署。
